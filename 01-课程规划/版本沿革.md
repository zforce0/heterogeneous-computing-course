## V6.4 相对 V6.3 的具体变化

1. **定位**：单校委托项目 → 标准化课程产品 + 学校适配层。
2. **交付物**：7 类 → 8 类，新增「实机异构平台」（可复现技术底座）与「展示材料」。
3. **实验平台**：由「实验平台与耗材」段的硬件清单，升级为独立成章的源码 + 部署文档 + 自检/打包脚本。
4. **脱敏**：学校名、Logo、报价金额全部占位符化；付款比例与商务结构保留为通用框架。
5. **复制能力**：新增《学校适配指南》，把「换一所学校」的成本从「重新定制」降为「改占位符 + 重排课 + 填报价」。
6. **教学框架与测评口径不变**：48 学时 / 3 学分 / 18 周 / 7 PPT / 4 实验 / 权重 15-20-25-40 / 基础 70 + 排名 30，跨校一致。

> V6.3 的完整报价、硬件单价、深职院案例保留在 `../Archive/课程规划旧版/`（原课程工作空间），作为标杆案例，不进入脱敏通用包。
