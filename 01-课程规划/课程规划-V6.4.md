# 《多核异构互联计算》课程规划 V6.4 · 可复制产品版

> 版本：V6.4 · 编制日期：2026-11-18
> 定位：**脱敏通用产品包**——学校名称、开发方、报价金额一律使用占位符，任何高校可据此复制定制。
> 开发模式：校企共建 / 企业委托开发，标准化课程产品 + 学校适配层。
> 技术基线：《Benchmark 实验设置手册 V1.1（实机版）》+ 实机异构平台（见第十章）。

## 执行摘要

V6.4 在 V6.3「单校定制」的基础上，把课程沉淀为**可复制、可售卖、可定制的标准化产品**：

- **保留不动的教学框架**：48 学时 / 3 学分 / 第五学期 / 18 周；7 套理论 PPT（30 页/堂）；4 个大实验课即 4 个大作业；理论全部前置且难度递进；评分表（15/20/25/40，基础 70 + 排名 30）；允许并鼓励使用 AI；10 套三端工位。
- **新增产品化能力**：
  1. 标准化教学包（理论 + 教具 + 手册 + 测评 + 实机平台）一次开发、多校复用；
  2. 「学校适配层」把校名、Logo、学时、硬件清单、报价、排课表全部做成可替换项；
  3. 面向教师的《教学实施手册》与面向校领导的《课程推介与立项建议》两份展示材料；
  4. 实机异构平台作为正式交付物，使课程从「纸面 PPT」升级为「可操作、可复现的工程实验」。
- **商务模式**：技术服务（课程开发 + 教学包 + 测评）计费，硬件按采购发票实报实销，利润主要来自非标定制件与平台集成。

## 四、7 个理论课 PPT

每套 30 页 / 90 分钟，7 套合计 210 页。「够用即止」：只覆盖紧随实验必须知道的知识，实机案例压到 1 页，空出 1 页做随堂练习。

| 讲次 | 主题 | 保留内容 | 删减内容 |
|---|---|---|---|
| PPT-1 | 异构计算导论 | 三堵墙、三端总览、四个核心指标 | 产业版图与规模定律 |
| PPT-2 | 互联与通信基础 | 链式双网线、三层转发、USB 带宽预算、ENOSPC | UVC alt 协商、TCP 拥塞控制推导 |
| PPT-3 | 体系结构与 Roofline | CPU/NPU/ISP 分工、算力与访存密度、读 Roofline 图 | Amdahl 推导、DMA 与缓存一致性 |
| PPT-4 | 并行与流水线 | 生产者—消费者、异步三级流水、有界队列与背压 | 锁与无锁队列、缓冲复用代价 |
| PPT-5 | 量化与端侧推理 | INT8、双 RKNN runtime、九段计时、P95 不相加 | 量化校准算法、算子回退 |
| PPT-6 | 性能评估方法论 | 基线、单因素对照、均值与波动、N/A、结果包、统一 UTC | bootstrap 与置信区间 |
| PPT-7 | 复盘与开放命题工作坊 | 前 3 次实验复盘、可测量问题定义、开题表 | ZeRO / vLLM / DoRA / 联邦学习 |

每讲固定结构：封面 → 目录（90 分钟节奏）→ 4 章（每章 3 内容页 + 1 实机案例 + 1 随堂练习）→ 故障口径速查 → 小结 → 课后任务 → 结束页。

## 五、教具包与实验手册

教具形态：可运行基线 + 留白脚手架 + selftest。留白点合计 18（必做 12 / 选做 6），学生做「跑通 + 单因素对照 + 报告」。

### （一）教具包通用结构（6 目录）

| 目录 | 状态 | 内容标准 |
|---|---|---|
| README.md | 给定 | 30 秒跑通命令、实机拓扑、依赖版本、安全约束 |
| config/ | 给定 + 留白 | `lab_given.yaml` 给拓扑与哈希；`student.yaml` 学生填 run_id 与策略 |
| baseline/ | 给定·完整 | 可运行最小基线，禁止修改 |
| student/ | 留白·骨架 | 接口签名已定，仅标 TODO[必做] 与 TODO[选做] |
| selftest/ | 给定 | 校验基线与必做 TODO，输出 PASS/FAIL + 原因 |
| runs/ | 输出 | 结果包目录，字段与测评包输入契约一致 |

### （二）4 个教具包

| 教具 | 给定基线 | 必做留白 | 选做留白 |
|---|---|---|---|
| M1 环境与链路 | inventory、网络核验、TCP 探测、manifest | 3 次 TCP 实测、均值波动、checksums | 多包长对比、并发流 |
| M2 双光谱采集 | camera_binding、带宽算术、双路并发基线 | by-path 核验、双路帧率、缺路标记 | 带宽切换对照 |
| M3 异构推理 | model_registry、双 runtime、九段计时 | 分段时延表、P50/P95、3 次运行 | INT8 对比、轻量消融 |
| M4 协同评测 | 证据协议、有界队列、结果包 schema | 端到端跑通、合法结果包、30 分钟记录 | 断流恢复注入 |

### （三）实验手册（4 册，固定 6 节）

1 实验目标与成功判据｜2 实机拓扑与安全约束｜3 教具包结构与 30 秒跑通｜4 当堂演示与当堂任务｜5 结果包规范与测量口径｜6 报告模板与 AI 登记。附录保留 5 条高频故障：网口接反、RV 无 IPv4、ENOSPC、error −71、ssh 百分号转义。

## 7. 测评包

5 个核心文件，学生可本地自查。

| 文件 | 职责 |
|---|---|
| `result_package.schema.json` | 结果包输入契约：标识/平台/可复现/采样/指标/证据六组字段 |
| `validate.py` | 校验必填字段、哈希、UTC、RUN_COMPLETE、checksums；填 0 判 invalid |
| `metrics.py` | 四实验排名指标：链路吞吐、双路有效帧率、端到端 P95、自定指标归一 |
| `rank.py` | 按分档生成排名分与排行榜 |
| `report.py` | 逐组反馈、证据快照、异议单；内嵌 fixtures |

基础分 70 = 自动核验 55（结果包合规 15 + 基线/selftest 15 + 必做 TODO 15 + 报告与 AI 登记 10）+ 人工复核 15。排名分档 30/27/24/20/16/12/0。防作弊 3 条：完成率 <0.95、静默丢路、时钟非统一 UTC。

## 八、AI 使用规范与小组分工

AI 政策：鼓励代码生成、调试、对照设计、报告草拟；须登记工具/模型/提示词要点/人工修改比例；禁止用 AI 生成测量数据、伪造结果包、代答答辩；现场随机抽代码要求解释；不因用 AI 扣分。

小组：3 人 3 岗——A 异构部署与调度、B 多模态数据与算法、C 互联可靠性与测量。个人成绩 = 小组得分 × 组内互评系数（0.9—1.1）。

## 十三、数据校验与待确认

- 学时：理论 7×2=14；大实验 4×6=24；导论讲评汇报 5×2=10；合计 48 = 3 学分。
- 教具留白：必做 3+3+3+3=12；选做 2+1+2+1=6；合计 18。
- 基础分：15+15+15+10=55 自动 + 15 人工 = 70；排名上限 30。
- 权重：15+20+25+40=100%。

待确认事项（随校）：非标件验收口径、工位覆盖排课、发票归档责任、耗材轮次摊配、AI 合规备案、教师职称认定佐证。
