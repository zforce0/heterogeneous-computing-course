4. **建分组**：3 人 × 12 组，分配 A/B/C 三岗（部署调度 / 多模态算法 / 互联测量）。
5. **试讲**：用 `../09-示范课教案/` 的第 3 讲 + 实验 2 公开课教案做一次完整走台。

## 2. 理论课怎么上（每讲 90 分钟）

每讲 PPT 固定 30 页，节奏建议：

| 时段 | 页 | 动作 |
|---|---|---|
| 0—10′ | 封面 + 目录 | 点明本讲与「下个实验」的关系 |
| 10—50′ | 4 章内容页 | 每章 3 页内容，讲「够用即止」 |
| 50—70′ | 实机案例（4 页） | 放现场采集的数据/截图，不空谈 |
| 70—85′ | 随堂练习（4 页） | 学生当场做，教师巡视 |
| 85—90′ | 小结 + 课后任务 | 布置与下个实验挂钩的任务 |

**关键**：每讲只讲「紧随实验必须知道的最小知识」，推导与前沿放到公式块，不展开。实机案例务必用本课程平台自己的数据（见 `../06-实验平台/docs/` 归档报告）。

## 3. 实验课怎么上（每次 6 学时三段）

```
教师演示(1h) → 当堂指导(2h) → 当堂开发(3h) → 课后(3次独立运行+报告)
```

### 3.1 教师演示（1 学时）

```bash
cd ../03-教具包/M1_lab_env && python3 selftest/teacher_demo.py
```

三场景演示：基线跑通 → 展示一个典型故障（如 ENOSPC、断流）→ 展示「补齐留白后」的预期输出。让学生**先看到终点再动手**。

### 3.2 当堂指导（2 学时）

- 学生只改 `student/todo_required.py`；`baseline/` 与 `config/lab_given.yaml` 禁改。
- 目标：完成必做 TODO → `python3 selftest/run_demo.py` 全 PASS → 产出第 1 个合法结果包（拿到基础分 70 的最小集）。

### 3.3 当堂开发（3 学时）

- 单因素对照（改一个变量、控其余）、选做 TODO、`--inject` 异常复现。
- 鼓励用 AI 生成/调试代码，但要求**登记 + 能现场解释**。

## 4. 考核怎么评

### 4.1 一次命令出成绩

```bash
cd ../05-测评包 && python3 run_eval.py
```

产出：逐组反馈、排行榜、异议单。基础分 70 = 自动核验 55 + 人工复核 15；排名分档 30/27/24/20/16/12/0。

### 4.2 口径红线（务必在 W1 就讲清楚）

- 分段 P95 相加 ≠ 端到端 P95。
- 跨板只报同钟 RTT，不比较两板墙钟。
- 未测值写 `N/A`，禁止填 0。
- 静默丢路（缺路不标 missing）直接判防作弊。

## 5. AI 使用规范落地

| 环节 | 允许 | 禁止 |
|---|---|---|
| 写代码 | 生成、调试、重构 | 生成测量数据 |
| 设计实验 | 对照设计、查资料 | 伪造结果包 |
| 写报告 | 草拟、润色 | 代答答辩 |

每份报告附「AI 使用登记表」：工具、模型、提示词要点、人工修改比例。答辩现场随机抽本组代码，要求解释。

## 6. 常见翻车与预案

| 症状 | 预案 |
|---|---|
| 板子拿不到 IP | 查 DHCP/静态地址误配（见 `../06-实验平台/docs/07-troubleshooting.md`） |
| 热成像无画面 | 先查 USB 接线；SDK 独占 usbfs，别按 video4linux 判断 |
| 学生 30 秒跑不通 | 用 `teacher_demo.py` 复现，多半是改了 `baseline/` 或 `lab_given.yaml` |
| 排行榜全 N/A | 结果包缺原始字段，回手册第 5 节核对 schema |
| LLM 答非所问 | 参考 `../06-实验平台/docs/` 里的 0.6B 提示词坑与后端兜底说明 |

## 7. 第一课怎么开（W1 模板）

1. 自我介绍 + 课程定位（用 `../07-展示材料/校领导版-*.md` 的「为什么」部分）。
2. 讲评分规则：4 大作业权重 15/20/25/40，基础 70 + 排名 30，无期末闭卷。
3. 讲 AI 政策：允许且鼓励，但登记 + 可复现 + 能答辩 + 不造假。
4. 讲安全：工位硬件、ADB 拔除、预览服务互斥、实机操作规范。
5. 现场 30 秒跑通一个教具包，让学生看到「这事我能做」。
6. 分组、定岗、发教具包与手册。
