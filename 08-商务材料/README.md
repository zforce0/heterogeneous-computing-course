# 08 · 商务材料

| 文件 | 用途 | 何时用 |
|---|---|---|
| `报价模板-脱敏.md` | 四段报价结构 + 岗位人月表 + 硬件清单 + 付款节点 | 定制某校时填金额出正式报价单 |
| `交付物清单与付款节点.md` | 8 类交付物 + 验收口径 + 不含项 | 签约谈判、验收对齐 |
| `合同与服务要点.md` | 知识产权、售后、数据隐私、多校复制条款 | 合同起草前的口径对齐 |

> 使用：复制为「`<校名>`-报价单-YYYYMMDD.md」等学校专属文件后再填金额，**不要**直接修改本脱敏模板。
> 交付某校前运行 `make check`（`scripts/check_placeholders.py`）确认占位符已全部替换。
