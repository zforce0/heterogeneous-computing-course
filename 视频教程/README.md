# 视频教程（使用指南）

本目录提供《多核异构互联计算》课程产品包的使用指南录屏视频。视频为控制台实机运行画面的**录屏演示**，展示真实界面与实时数据。

> 观看提示：视频里的双光画面、检测框、节点延迟、LLM 输出均为**现场实测数据**，会随实际运行变化；三个视频录制于不同时刻，因此数据状态略有差异。

## 视频清单

| 视频 | 时长 | 内容与观看重点 |
|---|---|---|
| `01-控制台总览.mp4` | ~6 s | 控制台整体：顶部四节点状态（MacBook / 昇腾 / RK3588 / RV1126B）、双光同屏、中心 LLM 面板、底部指标卡（在线节点 / tok/s / 帧率 / 推理耗时） |
| `02-双光同屏与端侧检测.mp4` | ~5 s | 双光同屏：左可见光 YOLOv8 检测框 + 模型条（`yolov8n_rv1126b.rknn · 640×480 · 76ms`）、右热成像 NPU/热斑 + 模型条（`256×192 · 121ms`）、目标筛选标签、帧率与推理耗时 |
| `03-中心LLM与事件研判.mp4` | ~5 s | 中心 LLM 面板：模型 `qwen3 0.6B`、系统提示、快捷提问 chip（近 1 分钟双光分析 / 近 1 分钟事件）、消息输入框与流式输出 |

> 视频为实机录屏、按 ~2.4× 加速合成（短视频便于快速浏览）；实际运行画面与视频一致，数据实时变化。

## 如何配合使用

- **备课**：先看 `01` 了解控制台全貌，再看 `../06-实验平台/docs/03-user-guide.md` 掌握每个区域的作用。
- **课堂演示**：用 `02` 向学生展示「端侧检测模型在真机上跑」的样子；对照 `../02-理论课-PPT/第5讲` 讲量化与端侧推理。
- **实机操作**：按 `../06-实验平台/README.md` 三档部署启动控制台，画面与本视频一致。

## 录制方式

视频由 `../scripts/record_screen.sh` 录制（macOS `screencapture` 连续抓帧 + `ffmpeg` 合成），脚本可复用：

```bash
bash scripts/record_screen.sh "视频教程/04-xxx.mp4" 15 3
```
